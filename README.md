# SuperIlógico · Opus Yeah

Landing del EP con enlaces de escucha, portada reversible y una página con las letras de las tres canciones. El sitio usa HTML, CSS y JavaScript del navegador. Para verlo en tu equipo, abre `index.html`.

## Publicar en GitHub Pages

1. Sube `index.html`, `letras.html`, `.nojekyll`, `README.md` y la carpeta `assets/` a la raíz del repositorio.
2. En el repositorio, abre **Settings → Pages**.
3. En **Source**, elige **Deploy from a branch**. Selecciona la rama donde subiste los archivos, normalmente `main`, y la carpeta **/(root)**. Guarda los cambios.
4. Cuando termine la publicación, abre la dirección que aparece en **Settings → Pages**.

[Guía de GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
